## 編目原則及資料限制

1. 現有 equipment_type_code 是單一值。雙功能機可先選現有主類型，副功能列在本報告／JSON；目前 importer 不會自動儲存副類型，不能聲稱更新後所有副功能都能被搜尋。長期宜支援機型與多個類型的關聯。
2. 對內收／外展、伸腿／屈腿、胸飛鳥／反向飛鳥等，主類型選擇是編目政策，並不表示另一功能較不重要。若要求單一類型完整表達所有功能，可改建對應 combo 類型，但不需要退回 Other。
3. 廣義類型如 elliptical_machine、climber、multi_press_machine 的適用範圍有條件；報告以中信心標註 AMT、Arc、梯式攀爬及 Jammer 等變式。若現有定義較窄，應建專用子類。
4. category=other 與 type=other_equipment 不同。體測儀可新增 body_composition_analyzer，即使父 category 暫用 other，仍是具體器材類型。
5. 原始 24/7 類別及中文也可能錯誤。DF-203 原始類別是 Cardio、MNOC 中文只寫外展、SUB 品牌可能誤標、MJLPD 圖片用通用 MJ 組合圖、LPP-CORE 是裸框架；不能不經核對就套名稱或品牌。
6. 所有主類型既有 code 都已對照本機 active equipment_types；所有 180 個 DB ID 只出現一次，沒有用 Other 或待辦預設值填補未審核項目。
